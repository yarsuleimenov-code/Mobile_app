## Правила обновления комплекта

Эта папка — намеренно выделенный срез для передачи, не второй редактируемый источник требований. Рабочие оригиналы находятся в репозитории в docs/. При изменениях обновлять оригиналы, затем выпускать новый согласованный срез комплекта; не править обе копии независимо. Текущий пакет v1.0 в docs/ не перемещён и его исходные контрольные суммы сохранены.

[MANIFEST.json](MANIFEST.json) — состав именно этой папки: source path, source hash и hash передаваемой копии. Ссылки в копиях адаптированы, поэтому их hash может отличаться от оригинала. Проверять package hash по UTF-8 тексту с переводами строк LF (CRLF нормализовать в LF). Файл current/DEVELOPMENT_PACKAGE_V1.0.json — исторический манифест **исходного** пакета docs/, не контрольная сумма адаптированных копий этой папки.

Прототип, исходный код, исследовательские HTML, build artifacts, credentials и локальные ignored DOCX/legacy audit не копируются в комплект. Исследования остаются отдельным контекстом, не обязательным scope. Подготовленный комплект не означает production готовность или закрытие RQ.
