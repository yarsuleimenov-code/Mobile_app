# Getting Started with Zaberman Mobile App

**Use this article when:** you are opening the app for the first time.

1. Open **Home**. You will see **Cargo operations** with Pickup and Dropoff actions.
2. Select **Load today’s route** if you need the sample stops. The list shows Order number, sequence, time, type and address.
3. Open **Tasks** to search an Order ID or title and filter All, Pickup or Dropoff.
4. Select the task card to open its operation. Use **Order details · Spoke preview** to inspect the order before recording cargo.
5. Use **Scan** to look up a PlaceID or Order ID; use **More** for Help & Instructions, Cargo places, Interstate and local sync.

**Expected result:** you are on the correct Pickup or Dropoff screen for the Order.

**Important:** the active build uses local sample tasks. Opening a task does not mark it complete. Administration in More controls test role, branch, connection and devices; it is not a regular field step.

**If something goes wrong:** if a stop is absent, check the search/filter or return Home and load today's route. For a complete walkthrough, see the [User Guide](../../docs/mobile-app/user-guide.md).
