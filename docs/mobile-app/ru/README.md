# Документация Mobile App

Zaberman Mobile App — будущий мобильный рабочий инструмент для сотрудников, выполняющих Pickup, Dropoff и Interstate-операции. Его бизнес-цель — собирать достоверные данные непосредственно в момент работы с грузом: подтверждать состав и количество грузовых мест, фиксировать размеры, фото, сканирование, подписи, документы и результат операции. Это позволит уменьшить ручной перенос информации, быстрее выявлять расхождения и сохранять последовательную историю движения каждого грузового места.

Целевое приложение должно поддерживать сбор данных при нестабильном соединении или без доступа к сети, сохранять операции на устройстве и синхронизировать их после восстановления связи. Интеграция со Spoke должна связывать мобильную работу с маршрутами, остановками и назначенными задачами, а интеграция с CRM — передавать подтверждённые результаты операций и актуальный статус заказа в общий процесс обслуживания клиента.

Текущая версия является бизнес-прототипом: она показывает фиксацию груза при Pickup, проверку при Dropoff и учёт отдельных грузовых мест при Interstate. Основная навигация — Home, Tasks, Scan и More. Действия с маршрутом, фото, подписями, печатью, синхронизацией и внешними системами сейчас имитируются локально в браузере; production-интеграции и надёжный offline-контур ещё не реализованы.

## Границы и проверка

Документы описывают активные маршруты [App.tsx](../../../wireframe/src/App.tsx), подключённые экраны и доменную логику. Принятые решения из [Stage 0](../../system-report/STAGE_0_PRODUCT_DECISIONS.md) обозначены как целевая модель, если активный интерфейс их ещё не выполняет. Старые компоненты, не подключённые к роутеру, не являются инструкцией для пользователя.

**Реализовано** — интерактивное поведение в браузере; **симуляция** — изменение локальных mock-данных; **планируется** — подтверждённая целевая модель без активного сценария; **неизвестно** — поведение нельзя надёжно установить из доступных источников.

Развёрнутая версия проверена в Chrome при ширине 390 px: Home → Tasks → Scan → More, Pickup → Dropoff → POD, поиск Scan, Interstate loading → Trip/BOL и приёмка с недостающими местами. На этих путях не возникло ошибок JavaScript. Скриншоты в руководстве сделаны с развёрнутого прототипа.
