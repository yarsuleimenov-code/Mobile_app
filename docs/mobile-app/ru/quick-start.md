# Краткое руководство

Короткая инструкция для текущего интерфейса Mobile App. Развёрнутая версия — бизнес-прототип: задачи и внешние действия имитируются и сохраняются в этом браузере.

## Перед началом

Откройте **Cargo operations**. Перед доступом к **Load today’s route** пройдите обязательный **Pre-trip inspection**. В wireframe Pickup и Dropoff можно открыть напрямую. Загруженный маршрут Spoke — локальный пример, а не актуальное назначение диспетчера.

## Как пройти предрейсовый осмотр

1. На Home нажмите **Start** в карточке Pre-trip inspection для **Van 08 · Extended Van**.
2. Ответьте **Pass** или **Issue** по всем семи пунктам безопасности.
3. Нажмите **Continue to photos** и сделайте обязательные фото Front, Rear, Driver side и Passenger side. Загрузка из галереи недоступна.
4. Проверьте результат и установите **I confirm this vehicle is safe to operate**.
5. Нажмите **Complete inspection**. На Home появится **Vehicle cleared**, после чего можно загрузить маршрут.

Любой **Issue** сохраняет блокировку маршрута. Нажмите **Review issues** и исправляйте ответ только после устранения проблемы либо действуйте по процедуре эскалации. Состояние Camera unavailable также блокирует завершение.

## Основное меню

- **Home:** Pickup, Dropoff, Today's stops, черновики и Order documents.
- **Tasks:** поиск по номеру/названию заказа, фильтр Pickup/Dropoff и открытие остановки.
- **Scan:** поиск PlaceID или Order ID.
- **More:** Help & Instructions, Cargo places, Interstate operations и статус локальной синхронизации.

## Как открыть задачу

В **Tasks** выберите остановку. Проверьте номер заказа, время и адрес. **Order details · Spoke preview** поможет посмотреть название и данные обработки груза. Открытие остановки само по себе не завершает задачу.

## Как написать или позвонить клиенту

Откройте **Messages** с Home, **Message customer** из задачи или Order details либо **SMS** в карточке заказа Pickup draft. Проверьте клиента и Order, выберите быстрый текст или введите свой, затем нажмите **Send**. Сообщение в очереди отправится после восстановления сети; для статуса **Not sent** используйте **Retry**. Отправитель — корпоративный номер **17178361039**, а не личный номер сотрудника.

Для звонка откройте диалог клиента, нажмите **Call**, проверьте Order и корпоративный номер **Calling from**, затем нажмите **Start call**. Завершите через **End call** и вернитесь по **Back to messages**. Текущая сборка показывает сценарий звонка, но не подключает аудио или провайдера телефонии.

## Как завершить Pickup

1. Проверьте номер и рабочее название заказа.
2. В каждой группе размеров укажите **Qty**, L/W/H и вес одного места. Для неизвестных величин добавьте причину.
3. Добавьте минимум одно фото и дождитесь сохранения черновика.
4. Нажмите **Continue to Pickup review**. При необходимости распечатайте или проверьте этикетки мест.
5. Проверьте материалы и комментарии. Выберите **Sign on device** либо **SMS code**. Для SMS code нажмите **Send verification code**, введите шестизначный код контакта и нажмите **Verify recipient**. В прототипе успешен любой шестизначный код, кроме `111111`.
6. Подтвердите контакт. Для подписи на устройстве нажмите **Continue to signing**, после OTP — **Continue to driver signature**. Получите подпись водителя Zaberman и нажмите **Confirm & lock Pickup snapshot**.

Первое сообщение об успешном сохранении означает готовность черновика. Передача подтверждена после подписания и блокировки Pickup snapshot.

## Как завершить Dropoff

1. Откройте остановку Dropoff или найдите номер заказа.
2. Сверьте места и фотографии Pickup с доставленным грузом.
3. Добавьте минимум одно фото Delivery. Отметьте **Cargo matches pickup photos** и **No visible damage** либо **Report damage instead** с описанием.
4. Нажмите **Confirm Dropoff**, затем **Open Delivery review**. Если UI требует, сначала подпишите Pickup.
5. Проверьте материалы и выберите способ подтверждения контакта: **Sign on device** или **SMS code**. Для SMS code отправьте код на показанный маскированный номер и введите код получателя. В прототипе подходит любой шестизначный код, кроме `111111`; этот код показывает ошибку.
6. Получите подпись водителя, нажмите **Complete Order eBOL** и откройте POD.

## Как использовать Scan

Откройте **Scan** и выберите **Scan label** или **Enter code manually**. Найденный PlaceID открывает место, Order ID — список его мест. Основной Scan только ищет. Для Interstate используйте поля PlaceID на экранах Loading или Unloading.

## Что делать при проблеме

Не подтверждайте неверный заказ или несовпадение груза. Исправьте черновик до подписания; после блокировки Pickup добавленные места оформляются через Supplemental Pickup. Неизвестный код Scan ничего не создаёт. Повреждение опишите через Report damage, а не отмечайте отсутствие повреждений. Если действие заблокировано, выполните шаг из предупреждения. Для ситуации без описанного пути обратитесь к ответственному за операцию.
