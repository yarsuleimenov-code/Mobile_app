# Краткое руководство

Короткая инструкция для текущего интерфейса Mobile App. Развёрнутая версия — бизнес-прототип: задачи и внешние действия имитируются и сохраняются в этом браузере.

## Перед началом

Откройте **Cargo operations**. Перед доступом к **Load today’s route** пройдите обязательный **Pre-trip inspection**. В wireframe Pickup и Dropoff можно открыть напрямую. Загруженный маршрут Spoke — локальный пример, а не актуальное назначение диспетчера.

## Как пройти предрейсовый осмотр

1. На Home нажмите **Start** в карточке Pre-trip inspection для **Van 08 · Extended Van**.
2. Ответьте **Pass** или **Issue** по всем четырём пунктам безопасности.
3. Нажмите **Continue to photos** и сделайте все 13 обязательных фото автомобиля и оборудования. Загрузка из галереи недоступна.
4. Проверьте результат и установите **I confirm this vehicle is safe to operate**.
5. Нажмите **Complete inspection**. На Home появится **Vehicle cleared**, после чего можно загрузить маршрут.

Любой **Issue** сохраняет блокировку маршрута. Нажмите **Review issues** и исправляйте ответ только после устранения проблемы либо действуйте по процедуре эскалации. Состояние Camera unavailable также блокирует завершение.

## После использования автомобиля

Home → **Post-trip inspection** → четыре проверки (каждый Issue с описанием) → 13 фото → Review и подтверждение водителя → **Complete Post-trip**. Подтвердите незавершённые остановки, если они есть. Дефекты не блокируют сдачу отчёта. Home → **Start next vehicle cycle** требует новый Pre-trip и сохраняет предыдущую пару в истории. [Подробная инструкция](user-guide.md#послерейсовый-осмотр).

## Основное меню

- **Home:** компактный блок **Manual operations → Pickup / Dropoff**, Today's stops, черновики и Order documents. Дополнительные места к подписанному Pickup: **Recent operations → Add places** или продолжение **Supplemental Pickup** из **Pickup drafts**.
- **Tasks:** поиск по номеру/названию заказа, фильтр Pickup/Dropoff и открытие остановки.
- **Scan:** поиск PlaceID или Order ID.
- **More:** Help & Instructions, Cargo places, Interstate operations и статус локальной синхронизации.

## Как открыть задачу

В **Tasks** выберите остановку. Проверьте номер заказа, время и адрес. **Order details · Spoke preview** поможет посмотреть название и данные обработки груза. Открытие остановки само по себе не завершает задачу.

В Tasks **Order details** — компактная ссылка рядом с пиктограммой сообщения клиенту. Водитель читает сводку и контакты без полей редактирования; **Additional details** раскрывает External name/Source. Особые требования остаются видимыми.

## Navigate

Проверьте полный адрес остановки на Home, Tasks, Pickup/Dropoff или Order details и нажмите **Navigate** для открытия Google Maps. **Copy address** копирует только адрес; при блокировке Clipboard доступно поле для ручного копирования. При нескольких остановках сначала выберите нужную. Открытие карт не завершает остановку. Если черновик не сохраняется, повторите попытку до ухода из формы. Обычный маршрут не гарантирует безопасность для грузового автомобиля.

## Team contacts

Откройте **Order details** в Pickup/Dropoff или Tasks: блок **Team contacts** расположен после сводки остановки. Проверьте заказ/остановку, нажмите **Copy summary** и вставьте текст в сообщение. Откройте **@nickname** диспетчера, брокера или менеджера в Telegram; автоматической отправки нет. При блокировке Clipboard скопируйте показанный текст вручную. Образцы Telegram-адресатов согласуйте до внешней демонстрации.

## Как написать или позвонить клиенту

Откройте **Inbox → Messages** с Home или из нижнего меню, **Message customer** из задачи или Order details либо **SMS** в карточке заказа Pickup draft. Проверьте клиента и Order. Первый шаблон **We'll be there in 20 minutes** («Будем через 20 минут») подставляет текст в редактор: измените минуты/текст при необходимости и нажмите **Send**. Автоматической отправки при выборе нет. Остальные шаблоны и свой текст доступны. Сообщение в очереди отправится после восстановления сети; для **Not sent** используйте **Retry**. Отправитель — корпоративный номер **17178361039**, а не личный номер сотрудника.

Для звонка нажмите **Call** в диалоге либо откройте **Inbox → Calls → Call back**; **Missed** показывает пропущенные. Проверьте Order, Route date и корпоративный номер **Calling from**, затем нажмите **Start call**. При нескольких совпадениях выберите заказ. Завершите через **End call** и вернитесь по **Back to messages** или **Back to calls**. Просмотр снимает индикатор новых пропущенных, сохраняя записи. Offline история доступна, Start запрещён. Звонки и история моделируются локально, без аудио и провайдера телефонии.

## Как завершить Pickup

1. Проверьте номер и рабочее название заказа.
2. В каждой группе размеров укажите **Qty**, L/W/H и вес одного места. Для неизвестных величин добавьте причину.
3. Добавьте минимум одно фото и дождитесь сохранения черновика.
4. Нажмите **Continue to Pickup review**. При необходимости распечатайте или проверьте этикетки мест.
5. Проверьте материалы и исключения. Выберите **Sign on device** либо **SMS code**. Каждая сторона вводит необязательный **Your comment** на своём экране подписания. При SMS code запишите **Contact comment (reported)** до проверки кода; водитель комментирует на своём экране подписи. Нажмите **Send verification code**, введите шестизначный код контакта и нажмите **Verify recipient**. В прототипе успешен любой шестизначный код, кроме `111111`.
6. Подтвердите контакт. Для подписи на устройстве нажмите **Continue to signing**, после OTP — **Continue to driver signature**. Получите подпись водителя Zaberman и нажмите **Confirm & lock Pickup snapshot**.

Первое сообщение об успешном сохранении означает готовность черновика. Передача подтверждена после подписания и блокировки Pickup snapshot.

## Как завершить Dropoff

1. Откройте остановку Dropoff или найдите номер заказа.
2. Сверьте места и фотографии Pickup с доставленным грузом.
3. Добавьте минимум одно фото Delivery. Отметьте **Cargo matches pickup photos** и **No visible damage** либо **Report damage instead** с описанием.
4. Нажмите **Confirm Dropoff**, затем **Open Delivery review**. Если UI требует, сначала подпишите Pickup.
5. Проверьте материалы и выберите способ подтверждения контакта: **Sign on device** или **SMS code**. Для SMS code отправьте код на показанный маскированный номер и введите код получателя. В прототипе подходит любой шестизначный код, кроме `111111`; этот код показывает ошибку.
6. Получите подпись водителя, нажмите **Complete Order eBOL** и откройте POD.

## Как использовать Scan

Откройте **Scan** и выберите **Scan label** или **Enter code manually**. Найденный PlaceID открывает место, Order ID — список его мест. Основной Scan только ищет. Для Interstate используйте поля PlaceID на экранах Loading или Unloading.

## Что делать при проблеме

Не подтверждайте неверный заказ или несовпадение груза. Исправьте черновик до подписания; после блокировки Pickup добавленные места оформляются через Supplemental Pickup. Неизвестный код Scan ничего не создаёт. Повреждение опишите через Report damage, а не отмечайте отсутствие повреждений. Если действие заблокировано, выполните шаг из предупреждения. Для ситуации без описанного пути обратитесь к ответственному за операцию.
