# Краткое руководство

Короткая инструкция для текущего интерфейса Mobile App. Развёрнутая версия — бизнес-прототип: задачи и внешние действия имитируются и сохраняются в этом браузере.

## Перед началом

Профиль сотрудника в **More** показывает **John Doe**. Новые подтверждения водителя и осмотры автоматически используют это имя. Поле **Driver name** доступно только для чтения. Имя клиента вводите отдельно, когда его запрашивает экран.

Откройте **Cargo operations**. Перед доступом к **Load today’s route** пройдите обязательный **Pre-trip inspection**. В wireframe Pickup и Delivery можно открыть напрямую. Загруженный маршрут Spoke — локальный пример, а не актуальное назначение диспетчера.

## Как пройти предрейсовый осмотр

1. Нажмите **Start** в карточке Pre-trip на Home.
2. Зафиксируйте четыре стороны автомобиля и приборную панель, введите одометр в милях и нажмите **Continue to equipment**.
3. Сделайте восемь фото оборудования, нажмите **Review inspection**, подтвердите запись и нажмите **Complete inspection**. На Home откроется загрузка маршрута.

## После использования автомобиля

Если был маршрут, по возвращении на склад нажмите **Complete route** на Home. Отдельно откройте **Post-trip inspection**. Зафиксируйте те же 13 фото, введите конечный одометр и проверьте пробег, если есть оба показания. Подтвердите запись и нажмите **Complete Post-trip**. **Start next vehicle cycle** переносит пару в историю. [Подробная инструкция](user-guide.md#послереисовыи-осмотр).

## Загрузите завтрашний рейс

Откройте **Route Loading** на Home и проверьте маршрут. Посмотрите **Broker photos** и **Packing photos**. Нажмите **Start loading**, затем отсканируйте QR-этикетку или введите **PlaceID** каждого места Delivery из списка. Когда все места подтверждены, нажмите **Complete loading**. [Подробная инструкция](user-guide.md#загрузка-завтрашнего-реиса).

## Синхронизируйте данные после восстановления связи

Нажмите **More → Sync now**. Откройте **Queue details**, чтобы проверить результат. Если запись показывает **Retry needed**, нажмите **Sync now** ещё раз. [Подробная инструкция](user-guide.md#синхронизация-сохраненных-изменении).

## Основное меню

- **Home:** компактный блок **Manual operations → Pickup / Delivery**, Today's stops, черновики и Order documents. Дополнительные места к подписанному Pickup: **Recent operations → Add places** или продолжение **Supplemental Pickup** из **Pickup drafts**.
- **Tasks:** поиск по номеру/названию заказа, фильтр Pickup/Delivery и открытие остановки.
- **Scan:** поиск PlaceID или Order ID.
- **Inbox** открывает Messages & Calls.
- **More:** Help & Instructions, Cargo places, Interstate operations и статус локальной синхронизации.

## Как открыть задачу

В **Tasks** выберите остановку. Проверьте номер заказа, время и адрес. **Order details · Spoke preview** поможет посмотреть название и данные обработки груза. Открытие остановки само по себе не завершает задачу.

В Tasks **Order details** — компактная ссылка рядом с пиктограммой сообщения клиенту. Водитель читает сводку и контакты без полей редактирования; **Additional details** раскрывает External name/Source. Особые требования остаются видимыми.

## Navigate

Проверьте полный адрес остановки на Home, Tasks, Pickup/Delivery или Order details и нажмите **Navigate** для открытия Google Maps. **Copy address** копирует только адрес; при блокировке Clipboard доступно поле для ручного копирования. При нескольких остановках сначала выберите нужную. Открытие карт не завершает остановку. Если черновик не сохраняется, повторите попытку до ухода из формы. Обычный маршрут не гарантирует безопасность для грузового автомобиля.

## Team contacts

Откройте **Order details** в Pickup/Delivery или Tasks: блок **Team contacts** расположен после сводки остановки. Проверьте заказ/остановку, нажмите **Copy summary** и вставьте текст в сообщение. Откройте **@nickname** диспетчера, брокера или менеджера в Telegram; автоматической отправки нет. При блокировке Clipboard скопируйте показанный текст вручную. Образцы Telegram-адресатов согласуйте до внешней демонстрации.

## Как написать или позвонить клиенту

Откройте **Inbox → Messages** с Home или из нижнего меню, **Message customer** из задачи или Order details либо **SMS** в карточке заказа Pickup draft. Проверьте клиента и Order. Первый шаблон **We'll be there in 20 minutes** («Будем через 20 минут») подставляет текст в редактор: измените минуты/текст при необходимости и нажмите **Send**. Автоматической отправки при выборе нет. Остальные шаблоны и свой текст доступны. Сообщение в очереди отправится после восстановления сети; для **Not sent** используйте **Retry**. Отправитель — корпоративный номер **17178361039**, а не личный номер сотрудника.

Для звонка нажмите **Call** в диалоге либо откройте **Inbox → Calls → Call back**; **Missed** показывает пропущенные. Проверьте Order, Route date и корпоративный номер **Calling from**, затем нажмите **Start call**. При нескольких совпадениях выберите заказ. Завершите через **End call** и вернитесь по **Back to messages** или **Back to calls**. Просмотр снимает индикатор новых пропущенных, сохраняя записи. Offline история доступна, Start запрещён. Звонки и история моделируются локально, без аудио и провайдера телефонии.

## Как завершить Pickup

1. Проверьте номер и рабочее название заказа. На назначенной точке нажмите **Start Pickup** в начале работы.
2. В каждой группе размеров укажите **Qty**, L/W/H и вес одного места. Для неизвестных величин добавьте причину.
3. Добавьте минимум одно фото и дождитесь сохранения черновика.
4. Нажмите **Continue to Pickup review**. При необходимости распечатайте или проверьте этикетки мест.
5. Проверьте материалы и исключения. Выберите **Sign on device** либо **SMS code**. Каждая сторона вводит необязательный **Your comment** на своём экране подписания. При SMS code запишите **Contact comment (reported)** до проверки кода; водитель комментирует на своём экране подписи. Нажмите **Send verification code**, введите шестизначный код контакта и нажмите **Verify recipient**. В прототипе успешен любой шестизначный код, кроме `111111`.
6. Подтвердите контакт. Для подписи на устройстве нажмите **Continue to signing**, после OTP — **Continue to driver signature**. Получите подпись водителя Zaberman и нажмите **Confirm & lock Pickup snapshot**.

После подтверждения передачи на назначенной точке нажмите **Complete stop**. Фото упаковки можно добавить позже через **Add packing photos** в подписанном Pickup или **Order details**.

## Как завершить Delivery

1. Откройте остановку Delivery или найдите номер заказа. На назначенной точке нажмите **Start Delivery** в начале работы.
2. Сверьте места и фотографии Pickup с доставленным грузом.
3. Добавьте минимум одно фото Delivery либо, если есть повреждение, нажмите **Record damage**, добавьте фото повреждения и опишите его.
4. Нажмите **Continue to Delivery review**, затем **Open Delivery review**. Если UI требует, сначала подпишите Pickup.
5. Проверьте материалы и выберите способ подтверждения контакта: **Sign on device** или **SMS code**. Для SMS code отправьте код на показанный маскированный номер и введите код получателя. В прототипе подходит любой шестизначный код, кроме `111111`; этот код показывает ошибку.
6. Получите подпись водителя, нажмите **Complete Order eBOL** и откройте POD.
7. На назначенной точке после подтверждения передачи нажмите **Complete stop**.

## Как использовать Scan

Откройте **Scan** и выберите **Scan label** или **Enter code manually**. Найденный PlaceID открывает место, Order ID — список его мест. Основной Scan только ищет. Для Interstate используйте поля PlaceID на экранах Loading или Unloading.

## Как запустить готовый сценарий

Откройте **More → Administration → Owner-demo rehearsal**. **Complete route & Post-trip** начинает показ с возврата на склад, **Next-day route loading** открывает завтрашнюю загрузку с фото брокеров, **Partial sync & retry** открывает More с тестовыми записями очереди. Повторное открытие продолжает сохранённую работу. Для подготовки примера завершения рейса сначала завершите другой активный цикл машины. [Инструкция по сценариям](user-guide.md#сценарии-в-administration).

## Что делать при проблеме

Не подтверждайте неверный заказ или несовпадение груза. Исправьте черновик до подписания; после блокировки Pickup добавленные места оформляются через Supplemental Pickup. Неизвестный код Scan ничего не создаёт. Зафиксируйте повреждение через **Record damage**. Если действие заблокировано, выполните шаг из предупреждения. Для ситуации без описанного пути обратитесь к ответственному за операцию.
