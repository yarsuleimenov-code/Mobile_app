# MOB — Предрейсовый осмотр

Дата: 2026-09-28
Статус: hi-fi wireframe для бизнес-валидации

## Цель

Перед доступом к дневному маршруту водитель подтверждает безопасность назначенного автомобиля, проходит обязательный чек-лист и делает четыре фотографии непосредственно через камеру.

## Scope wireframe

- точка входа на Home перед загрузкой маршрута;
- автомобиль `Van 08 · Extended Van`, филиал `NJ1`;
- семь обязательных групп проверки;
- ответы `Pass` или `Issue` по каждому пункту;
- четыре обязательных ракурса: Front, Rear, Driver side, Passenger side;
- только действие `Take photo`, без выбора из галереи;
- подтверждение водителя о безопасности автомобиля;
- блокировка маршрута при незаполненном осмотре или отмеченной неисправности;
- сохранение состояния в `localStorage`;
- Camera unavailable управляется через More → Administration;
- Reset all mock data сбрасывает осмотр вместе с остальными данными wireframe.

## Зафиксированные допущения

- Wireframe не использует реальную камеру и не сохраняет бинарные файлы.
- Любой `Issue` блокирует маршрут. Деление дефектов на critical/non-critical остаётся production-решением.
- Реальное назначение автомобиля, supervisor override, ремонтная задача, GPS, timestamp от сервера и object storage находятся вне scope.
- Пройденный осмотр действует для демонстрируемого дневного маршрута до сброса данных.

## Основной сценарий демонстрации

1. На Home маршрут заблокирован карточкой Pre-trip inspection.
2. Водитель проходит семь проверок, выбирая `Pass`.
3. Водитель последовательно делает четыре обязательные фотографии.
4. На Review водитель подтверждает безопасность автомобиля.
5. После завершения Home показывает `Vehicle cleared`, а загрузка маршрута становится доступной.

## Негативный сценарий

1. На любом пункте выбрать `Issue`.
2. Завершить остальные проверки и фотографии.
3. Review показывает `Route locked`; кнопка завершения недоступна.
4. Вернуться через `Review issues`, исправить ответ и завершить осмотр.

## Критерии бизнес-приёмки

- пользователь понимает, почему маршрут заблокирован;
- осмотр нельзя завершить без каждого ответа и каждого ракурса;
- галерея не предлагается как источник фото;
- неисправность визуально блокирует допуск;
- после успешного осмотра маршрут доступен без дополнительных действий администратора;
- flow читаем на мобильной ширине 390 px и desktop preview.
